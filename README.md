# VibeStream

# 🎧 Music Streaming Platform with Recommendation System

A full-stack Spotify-like music streaming application built using Flask, React, and PostgreSQL.

## 🚀 Features
- User authentication (JWT)
- Audio streaming with range requests
- Playlist management
- Listening history tracking
- Personalized recommendations (ML)

## 🛠️ Tech Stack
- Backend: Flask, SQLAlchemy
- Frontend: React, Tailwind CSS
- Database: PostgreSQL
- ML: Cosine similarity
